# Algorithm

Personal repository for algorithm implementations, problem-solving, and visualizers in C++ and Python.

## Structure

- `sort/`: Classic sorting algorithms (Quick Sort, Merge Sort, Heap Sort, Counting Sort, Radix Sort)
- `dp_greedy/`: Dynamic programming and greedy solutions (Knapsack, LCS, state traversal)
- `graph/`: Graph algorithms (Dijkstra, Minimum Spanning Tree)
- `practice/`: Problem-solving and competitive programming practices (Bellman-Ford, Binary Search on Answer)
- `visualization/`: Python scripts for visualizing sorting and graph traversal steps

## Development

- **Python & C++ Setup**: See [python_cpp_guide.md](python_cpp_guide.md) for environment setup and script execution.
- **Compile C++**:
  ```bash
  g++ -std=c++17 -O2 <file>.cpp -o main
  ./main
  ```
